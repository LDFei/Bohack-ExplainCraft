# 素材库导航化与中央面板减负

设计日期：2026-11-14。范围是 Tauri 工作台 `front/` 的三栏布局，不涉及后端与数据契约。

## 问题

当前左侧栏、中央画布和右侧对话之间大量功能重复，视觉上显得拥挤：

- 左侧栏同时承担：素材列表（「视频片段」「已上传」两个 tab）、生成分镜缩略图、创作历史项目列表、
  中部一个「上传媒体」大按钮，以及底部「本地工作空间」状态；四类互不相关的信息挤在一栏里。
- 上传入口有三处：左侧工具栏「上传」、左侧中部大按钮、中央「素材」tab 内的上传按钮。
- 素材展示有两处：左侧「已上传」列表和中央「素材」tab 网格。
- 分镜展示有两处：左侧「视频片段」列表和中央「脚本」tab 的镜头卡片。
- 中央「音频」tab 把配音音色/语速与背景音乐选择、旁白音量、音乐音量混在同一表单里，
  背景音乐候选又来自素材库的音频，概念交错。
- 创作历史与素材无关，却被固定在素材栏底部。

## 方案

选择方案 A：左侧栏改为「导航 + 内容面板」结构，中央面板去掉重复内容。

### 1. 左侧栏

工具栏（rail）固定四个导航项，点击切换右侧面板内容：

| 导航项   | 面板内容                                       |
| -------- | ---------------------------------------------- |
| 素材库   | 上传入口 + 图片 / 视频 / 音频 分组的素材网格   |
| 历史创作 | 新建创作、搜索、项目列表（状态、重命名、删除） |
| 模板     | 保持现有行为，打开模板弹窗                     |
| 设置     | 保持现有行为，打开工作台设置                   |

- 素材库面板顶部是唯一的素材上传入口：「＋ 添加素材」，同时整个面板是拖拽投放区。
- 素材按 `Asset.kind` 分为 **图片 / 视频 / 音频** 三组，组标题带数量，可折叠；
  分组内为缩略图网格，图片/视频显示缩略图，音频显示波形样式占位与文件名。
- 音频卡片提供「试听」和「设为背景音乐」两个轻量操作；素材为 `processing` 或 `failed` 时
  卡片显示状态角标，与现有 `Asset.status` 一致。
- 搜索框只过滤素材库内的素材，不再兼作项目搜索。
- 移除左侧中部独立大按钮与「视频片段」「已上传」两个旧 tab；移除底部「本地工作空间」状态条
  （信息量低、占空间）。
- 历史创作面板保留现有项目卡片、状态文案、重命名/删除菜单和「新建创作」。

### 2. 中央面板

- 标签改为 **脚本 / 声音 / 设置** 三项，去掉「素材」标签，素材统一在左侧素材库管理。
- 「脚本」保留分镜卡片列表与文案编辑，行为不变。
- 「声音」拆为两张卡：
  - **配音**：音色选择、语速；说明文案注明配音由生成流程产出。
  - **背景音乐**：来源选择（自动生成 / 不生成 / 曲库曲目 / 素材库音频），
    素材库音频选项标注来源，试听按钮只在有示例音时显示；音乐音量归入此卡。
  - 旁白音量归入配音卡。
- 「设置」保持不变。
- 删除中央「素材」tag 内重复的上传区与素材网格。

### 3. 交互与状态

- 素材库与历史创作面板切换只改变左侧面板内容，不改变工作区三栏宽度、时间轴高度或后端状态。
- 点击素材卡片不自动改变镜头；「设为背景音乐」通过现有草稿表单路径写入 `audio.music_*`，
  与中央「声音」面板的选择保持同一份草稿数据。
- 历史版本（只读）状态下，素材库只读展示，「设为背景音乐」禁用，与现有 `disableForm` 一致。

## 不做的事

- 不修改后端接口、数据模型或 `Asset` 字段。
- 不修改时间轴、播放器、Copilot 对话及其附件上传（对话附件是输入上下文，与素材库用途不同）。
- 不修改三栏拖拽布局与主题系统。

## 验收

- 素材上传只有素材库一个入口；拖拽文件到素材库面板可上传。
- 图片、视频、音频在素材库内分组展示，数量正确。
- 中央面板不再出现素材 tab 与重复上传入口。
- 「声音」面板的配音与背景音乐分区清晰，选择素材库音频后保存并重新生成时仍生效。
- 历史创作从素材库中独立出来，可从 rail 一键进入。
- `npm run build:studio` 通过。
