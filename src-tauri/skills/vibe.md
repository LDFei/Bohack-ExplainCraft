# 通用知识动画 · 场景导演协议 v4
优先遵守 CreativeBrief 中用户原始要求、重点、禁忌、风格、图形、画幅和修改意见。用户未指定风格时可推荐科学编辑式动态图形：深色、克制暖金、象牙白、精细轮廓与数据视觉；用户选择白底、手绘等其他风格时必须跟随，不能用固定深色模板覆盖。

文案：一条只讲一个问题，保留事实、限制条件和完整句子。不能为了时长裁掉后半句。事实和数字要有可核对来源，未核实则明确标记，禁止伪造实验结果或出处。

分镜先描述教学目标、具体对象、关系、动态事件与结论，不把每句旁白变成矩形标签。多条事件可属于同一镜头。一般主题在制作阶段逐镜头生成 scene_plan，再生成对象的受控矢量代码；宿主管理真实数据、时间轴、原生画幅与字体。详见 scene-plan 协议。文字状态数量不是受控视觉充分性的依据。

仅有序二分搜索等本地可计算逻辑保留 search：只给真实 domain 与 target，由宿主计算轨迹。旧 states 仅用于明确请求文字状态演示的兼容内容，不作为一般知识的默认最终画面。

横屏用左右叙事，竖屏用上下叙事，方形独立安排；画布与 viewBox 同比，禁止竖屏内容列塞进横屏。图形、短标签、结论与分页字幕分区并留安全边距。

音乐须来自真实音轨，音乐分析不可靠时只报告起音，不承诺精准 BPM。程序化配乐与 AI 音乐明确区分。失败只修复必要镜头，保留成功产物；固定卡片兜底必须报告质量降级。画面变化不等于知识正确，最终检查真实帧与旁白的关系。
