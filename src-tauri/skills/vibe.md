# 国内 Vibe 知识大赏 · 固定视觉协议 v3
默认输出深色背景、大字、几何图解、音乐驱动的知识短片。画面由固定的 SVG/HTML 模板生成，不把任意模型图片叫作 Vibe。
视觉基线：#0B1120 深蓝黑背景，#F4F7FF 正文，单镜头最多一种强调色；竖屏主标题约 52px，节点约 27px，字幕约 26px；统一安全边距。主标题、图形、字幕分区，不让文字彼此覆盖。避免照片拼贴、花哨贴纸或默认白底幻灯片。
文案：一条只讲一个问题，反直觉开场 → 解释机制 → 例子 → 条件与边界 → 一句结论。保留用户提供的事实、限制条件和完整句子。不能为了时长直接裁掉后半句话或镜头。事实/数据必须有可核对来源，未核实内容明确标记，不能伪造出处。
分镜 visual_prompt 必须是 JSON 字符串；"kind"、"title"、"labels"、"note" 仍是兜底字段。能表达知识变化时，增加受约束的 visual 指令，由宿主执行动画，模型不提供坐标或代码：
- {"type":"search","domain":{"from":1,"to":100},"target":74,"conclusion":"7 次比较命中 · O(log n)"}：在有序整数空间中查找目标。只给真实区间和目标，宿主会本地真实计算每一步中点、比较结果与排除区间，禁止自己编造查找过程。
- {"type":"states","states":[{"caption":"这一步的推理","objects":[{"text":"对象","emphasis":"accent|plain|dim"}]}],"conclusion":"最终结论"}：2～5 个状态，每个状态对应一条真实推理；同一文字在相邻状态出现时会被连续移动，新对象淡入、离场对象淡出。不要把整段解说拆成矩形文字框。
对象文字必须对应本镜头的真实概念，不使用没有依据的百分比和数值。图形表达因果、对比、循环或数据变化，禁止所有镜头只换字不换表达。
音乐在分镜审阅前准备并分析；只有真实音轨分析后的拍点可以驱动动画。信号不可靠时说明只检测到起音，不承诺精准BPM。音乐来源可为本地上传、AI API生成、原版示例，程序化配乐单独标明。
固定模板保证视觉基线，内容正确性与传播效果需要用户审阅和真实成片对照，不承诺复刻某位作者作品。
