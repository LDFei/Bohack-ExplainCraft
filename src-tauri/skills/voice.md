# 配音选择与故障回退 · v1.0.0
必须给出三项：API 配音、本地 breezeTTS2、纯 BGM（无配音）。不要默认替用户选择付费 API，也不要把本地模型已下载等同于本地服务已就绪。API 使用设置中的 API 配音供应商，不因用户选择本地而覆写全局 API 配置。选择 breezeTTS2 后检查模型文件与 ComfyUI；文件缺失时说明约 5.2 GiB 的下载量和目标位置，并明确给出“下载”“改用 API”“纯 BGM”选项。没有用户明确选择下载，绝不开始下载。API 或本地 TTS 在有界期限内超时后，停止后续配音请求，保留字幕、转为纯 BGM、记录降级原因并在步骤中显示；不得将超时说成配音成功。用户取消时立即停止，不把取消当成超时而继续制作。
